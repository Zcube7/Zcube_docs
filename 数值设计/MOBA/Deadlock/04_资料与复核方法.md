# 资料与复核方法

[返回总览](README.md)

## 1. 用哪种资料回答哪个问题

| 证据 | 能回答的问题 | 引用时应记录 | 常用入口 |
| --- | --- | --- | --- |
| Valve 公告与开发者发言 | 某次补丁改了哪些值、触发条件或交互。开发者在文中明确解释了哪些取舍 | 公告日期、适用模式、改动前后值。同日可能有后续修正 | [官方论坛更新日志](https://forums.playdeadlock.com/forums/changelog.10/) · [Steam 新闻](https://store.steampowered.com/news/app/1422450) |
| 客户端配置与差异 | 某个构建的基础值、成长、技能参数、装备价格和地图单位数据。两次构建之间哪些字段发生变化 | 客户端版本或 Steam Build ID，保留来源使用的编号类型。抄录字段、单位和数值 | [deadlock.gs 数据来源](https://deadlock.gs/about/) · [Frogtech 差异说明](https://changelog.frogtech.dev/about) |
| 社区 Wiki | 同一个英雄的技能、升级档位、操作条件、道具交互及历史记录 | 页面查阅日。精确数值再找同版本公告、配置或实测 | [Infernus 页面](https://deadlock.wiki/Infernus) · [Infernus 更新历史](https://deadlock.wiki/Infernus/Update_history) |
| 游戏内沙盒 | 在指定装备、距离、抗性与触发条件下实际发生了什么 | 构建、操作者与目标条件、重复次数、逐笔日志 | [Valve 沙盒工具说明](https://www.playdeadlock.com/cityneversleeps?pubDate=20260929) |
| 社区对局样本 | 某个版本和人群里的胜率、选取率、禁用率与对局数量 | 版本、日期范围、模式、段位、各项指标的分母 | [Deadlock API 英雄统计](https://deadlock-api.com/analytics/heroes) · [API 文档](https://api.deadlock-api.com/docs) |

公告适合定位改动理由和历史起点。配置站和 Wiki 可能在不同时间更新，比较前先核对版本。客户端字段有可能属于原型、遗留项或界面文案，生效条件与执行顺序要查公告或实测。Frogtech 可定位未写入公告的字段变化，部分早期更新仅存公告。将玩法动机写为「分析推断」，把 Valve 明示的原因紧跟原文链接。[Frogtech 覆盖说明](https://changelog.frogtech.dev/about)

## 2. 复核一条技能数据

1. **把问题写成可观察的事件。** 例如「给技能升二档后，额外伤害的 Spirit 系数是多少」或「格挡窗口内，哪几类命中能解锁追击」。分开记录每跳伤害与总伤害、触发与可选后续动作。
2. **锁定测试条件。** 写下构建、英雄、Boon 和升级档位。固定目标类型、抗性、护盾、距离、标记与其他装备效果。每次只改变一个变量。用不同 Spirit 值测系数时，确认改变 Spirit 的道具没有额外增伤或减抗，前后比较同一伤害事件。
3. **保留可复现的输入和输出。** 沙盒可录制并重复播放机器人的动作，调整目标属性，查看伤害事件、增减益和武器衰减提示。测单发伤害时保存逐笔战斗日志。测武器持续输出时写明采样时长、距离、装填是否计入，再记录 DPS。 [Valve 沙盒工具说明](https://www.playdeadlock.com/cityneversleeps?pubDate=20260929)
4. **检查边界和差异。** 对触发型技能，分别构造满足条件、离开触发窗口、命中不同目标的对照。两组伤害差除以两组 Spirit 差，可估算固定条件下的斜率。再用第三个点核对，留意显示取整、伤害减免、阈值和多段触发。

## 3. 复核补丁后的对局表现

按补丁切分时间窗，前后用相同模式、段位和统计口径，记录各自的日期、样本量、胜率、选取率和禁用率。即使胜率变动方向与预期一致，同期装备改动、新英雄、选用人群和对手结构也可能影响样本。表述为「该分组样本在补丁后观察到的变化」，玩法机制仍以公告、配置和沙盒复核支持。若时间窗跨热修，先拆开看，避免把不同构建混入同一组。 [Deadlock API 筛选项与指标说明](https://deadlock-api.com/analytics/heroes)

## 4. 复核记录模板

| 字段 | 填写项 |
| --- | --- |
| 问题与版本 | 英雄或系统、模式、补丁日期、构建号、查阅日 |
| 取证 | 官方原文链接、配置字段或 Wiki 页面、沙盒日志或对局样本链接 |
| 对照条件 | 前后构建或测试组、Boon、升级档位、装备、目标、距离、次数 |
| 结果与范围 | 原始值、单位、实测差异或样本分母，可复现的条件与待复核项 |
| 解读 | Valve 明示的目的、由结果推导的影响、仍需测试的假设 |
